# @edv4h/alter-ego-core

Headless avatar engine. `alter-ego` の中核パッケージ。

状態管理・スキーマ解釈・プラグインレジストリを提供する。描画・I/O は持たない。

詳細は [リポジトリのドキュメント](https://github.com/EdV4H/alter-ego/blob/main/docs) を参照。

## インストール

```sh
npm install @edv4h/alter-ego-core
```

ESM のみ。0.x の間は minor でも壊れる変更が入ることがある（[CHANGELOG](./CHANGELOG.md)）。
