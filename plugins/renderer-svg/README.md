# @edv4h/alter-ego-plugin-renderer-svg

SVG で描画する Renderer プラグイン。

## インストール

```sh
npm install @edv4h/alter-ego-plugin-renderer-svg @edv4h/alter-ego-core
```

ESM のみ。0.x の間は minor でも壊れる変更が入ることがある（[CHANGELOG](./CHANGELOG.md)）。

使い方はリポジトリの [クイックスタート](https://github.com/EdV4H/alter-ego/blob/main/README.md#クイックスタート) と [Renderer の書き方](https://github.com/EdV4H/alter-ego/blob/main/docs/plugins/renderer.md) を参照。
