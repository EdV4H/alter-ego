# @edv4h/alter-ego-plugin-loader-http

HTTP 経由でアセットを取得する Loader プラグイン。

## インストール

```sh
npm install @edv4h/alter-ego-plugin-loader-http @edv4h/alter-ego-core
```

ESM のみ。0.x の間は minor でも壊れる変更が入ることがある（[CHANGELOG](./CHANGELOG.md)）。

使い方はリポジトリの [クイックスタート](https://github.com/EdV4H/alter-ego/blob/main/README.md#クイックスタート) と [Loader の書き方](https://github.com/EdV4H/alter-ego/blob/main/docs/plugins/loader.md) を参照。
